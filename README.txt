# Haziq Zahid — Digital Marketing Portfolio

A responsive, single-page portfolio website built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content, SEO metadata, and Person structured data
- `style.css` — responsive visual design
- `script.js` — mobile menu, scroll progress, reveal effects, and inquiry email draft

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best results, use a local development server (for example, VS Code Live Server).

## Before publishing
- Add your real profile photo and genuine project screenshots/case studies.
- Replace illustrative portfolio cards with verified work before describing them as client projects.
- Add your actual email and WhatsApp number if you want direct contact links.
- The contact form currently opens an email draft using the visitor's default email application. It does **not** send or store submissions. For production, connect a secure form backend or form provider and update the privacy notice.
- Add your domain's canonical URL, sitemap.xml, and robots.txt before launch.
- Check all content and metadata after you choose your final domain.
- The Google Fonts stylesheet requires an internet connection; the page otherwise uses a system font fallback.

## SEO notes
The page includes a title, meta description, Open Graph tags, and basic Person structured data. Rankings are not guaranteed; continue publishing helpful content and measure performance through Google Search Console after launch.
